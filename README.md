# React Portfolio CMS

A static React portfolio website with:

- React + Vite
- Decap CMS
- GitHub-based content management
- Image uploads
- No backend required

---

# Features

✅ Static website  
✅ Add/Edit projects from CMS  
✅ Upload project images  
✅ GitHub auto commits  
✅ Vercel/Netlify deployment  
✅ No custom backend

---

# Tech Stack

- React
- Vite
- Decap CMS
- GitHub
- Vercel / Netlify
